# XML File Management & Parsing App

A cross-platform desktop application featuring advanced parsing strategies and cloud storage integration. 

## Features
* **Advanced Data Parsing:** Implements the Strategy design pattern using DOM, SAX, and LINQ for efficient XML data processing.
* **Cloud Integration:** Google Drive API integration for uploading and downloading files directly from the application.
* **Data Export:** Functionality to convert and export managed data into HTML and XML formats.
* **Cross-Platform UI:** Graphical user interface built with .NET MAUI.

## Tech Stack
* **Language:** C#
* **Framework:** .NET MAUI
* **Cloud:** Google Drive API

## Getting Started
1. Clone the repository.
2. Open the `.sln` solution file in Visual Studio (ensure the .NET MAUI workload is installed).
3. Restore NuGet packages and run the application on your local machine.
